\begin{abstract}
  We present an efficient algorithm for rational term unification in persistent settings
  which demonstrates a comparable performance w.r.t. the conventional \miniKanren
  unification with triangular substitution for Herbrand terms. Our algorithm is based
  on existing Martelli-Rossi approach and uses some adjustments to make the implementation
  more conventional. We provide certified proofs of principal algorithm properties
  in the \Rocq proof assistant and showcase the results of a comprehensive performance
  evaluation.
\end{abstract}
